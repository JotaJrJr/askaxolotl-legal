Ask Axolotl

A personal tool that creates short vertical quiz videos and sends them to its owner's own TikTok account.

What it does

Quiz Video Factory is a small program that runs on its owner's own computer. It turns a topic into a short quiz video (a question, four answer options, a countdown and the animated reveal of the correct answer), then lets the owner review the result and send it to the owner's own TikTok account, either as a draft or as a post.

How it uses TikTok

  • Login Kit – the owner signs in with their own TikTok account so the program can act on that account.
  • Content Posting API – the owner reviews each video, picks who can see it, and confirms before anything is sent. Nothing is posted without that explicit confirmation.

Who it is for

The program is not a public service. It has no public user accounts, no website sign-up and no hosted backend: it is used only by its owner, on the owner's own computer.
